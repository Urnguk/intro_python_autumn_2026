# Test_1: Linux Terminal

``` text
linux_test/
├── documents/
│   ├── report.txt
│   └── notes.txt
├── photos/
│   └── cat.jpg
├── backup/
└── old.txt
```

На старте вы находитесь в папке `linux_test`.

1.  Скопируйте `report.txt` в папку `backup`.
2.  Переместите `old.txt` в папку `documents`.
3.  Переименуйте `old.txt` в `old_notes.txt`.
4.  Скопируйте `cat.jpg` в папку `backup` под именем `cat_backup.jpg`.
5.  Удалите изначальный `cat.jpg`.
