1. Файл размером 100 МБ скачивается по частям. За каждую секунду загружается 12 МБ, а в последнюю — оставшаяся часть файла.

```python
remaining = 100
seconds = 0

while remaining > 0:
    remaining -= 12
    seconds += 1

print(seconds)
```

Что выведет программа? Почему используется условие `remaining > 0`, а не `remaining != 0`? Что произойдёт при такой замене?

2. Что выведет на экран данная программа?

```python
A = [2, 1, 3, 2]
s = 0

for i in range(len(A)):
    s += A[i]
    A[i] = s

print(A)
```

Запишите точно, что будет выведено на экран, и обоснуйте. Какова временная сложность программы в зависимости от длины списка `n`?
